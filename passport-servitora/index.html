Каждый шаг — разворот из двух страниц: сначала разбор решения, затем страница полей. В конце — чистовой паспорт, который можно распечатать и заполнить для собственной конструкции.

ТЕБЕ ПОДОЙДЁТ, ЕСЛИ

  • ты уже знаком с базовой рамкой хаос-магии
  • хочешь перейти от чтения к одной конкретной работе
  • готов фиксировать критерии, границы и собственные действия
  • нужен документ, к которому можно вернуться через месяц

НЕ ПОКУПАЙ, ЕСЛИ

  • ищешь гарантированный результат без собственных действий
  • хочешь передать сервитору ответственность за решения
  • тебе нужна только общая теория — она уже есть в бесплатном курсе
  • не готов остановить практику, если она мешает сну, работе или отношениям
